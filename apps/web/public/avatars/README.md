# Preset avatars

`preset-13.webp` through `preset-24.webp` are reproducible 256×256 WebP avatar assets. Run `pnpm avatars:generate` from the repository root to regenerate them.

- Source: [DiceBear Lorelei style documentation](https://www.dicebear.com/styles/lorelei/), generated through the official `https://api.dicebear.com/10.x/lorelei/svg` API.
- Creator: Lisa Wischofsky.
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
- Retrieved: 2026-08-23.
- Fixed seeds, in preset order 13–24: `Amber`, `Coco`, `Daisy`, `Emery`, `Felix`, `Ginger`, `Hazel`, `Jasper`, `Kiki`, `Luna`, `Milo`, `Nova`.

DiceBear is a build-time source only. The application serves the checked-in WebP files and makes no runtime request to DiceBear.
